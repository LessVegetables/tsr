## [2.9]: критерии

Для каждой регрессии y = β₀ + β₁·x проверяется H₀: β₁ = 0. Wald, LR и score считаются
через RSS ограниченной (только β₀) и полной модели и выводятся в F-форме
F = stat·(n − k)/(n·q) с df = (1, n − 2); Wald в этой форме совпадает с обычным F регрессии.
Ноутбук сверяет все три значения со statsmodels.
