## Запуск

Окружение — `../venv`. В нём в режиме editable стоят три собственные библиотеки,
так что их правки подхватываются без переустановки: `upsetkit`
(`../upset_plotting`), `raincloudkit` (`../raincloud_plot`), `scatterkit`
(`../scatter_plot`). В Google Colab их ставит первая ячейка ноутбука.

```bash
../venv/bin/python -m jupyter lab task1.ipynb
```

Либо прогнать целиком без интерфейса:

```bash
../venv/bin/python -c "import nbformat,nbclient;nb=nbformat.read('task1.ipynb',as_version=4);nbclient.NotebookClient(nb,timeout=1200,resources={'metadata':{'path':'.'}}).execute();nbformat.write(nb,'task1.ipynb')"
```

## Параметры

Все настройки собраны в одной ячейке ноутбука (`ПАРАМЕТРЫ ПОЛЬЗОВАТЕЛЯ`):
пары признаков, доли удаляемых ячеек, выбранный `dfSdXX` для [1.8], список
методов заполнения и стили графиков: `RAIN` (`raincloudkit.RainStyle`) и
`SCATTER` (`scatterkit.Style`).

Оценки в ящике raincloud-графика меняются через `BoxSpec(center=..., box=...,
whisker=...)` из `raincloudkit`: центр — медиана / среднее / квантиль / своя функция, тело — IQR /
±std / ±SEM / пара процентилей, усы — полный размах / 1.5·IQR / пара процентилей.

## [1.9]: что именно считается UpSet-графиком

Графики строятся вызовом `plot_upset()` из собственного модуля `upsetkit`.

* **(а) пропуски** — условие на признак «значение отсутствует»; пересечения
  перечисляют все комбинации признаков, пропавших у объекта вместе.
* **(б) совпадающие значения** — условие «значение объекта по этому признаку
  совпадает со значением другого объекта». На непрерывных данных совпадений нет
  вовсе, зато они массово появляются после заполнения константой, поэтому (б)
  читается как отпечаток метода импутации.
  Альтернативное чтение — `upset_pairwise_equal()`, по одному условию на пару
  признаков (`A=B`, `A=C`, …) с допуском `atol`.

`upsetplot` молча выбрасывает условия, которых не выполняет ни один объект, —
например признак без единого пропуска просто исчез бы из матрицы. Поэтому
`t1lib/upsetviews.py` сам проверяет индикаторы, печатает предупреждение с
именами пустых условий и возвращает `None` вместо пустого графика.
